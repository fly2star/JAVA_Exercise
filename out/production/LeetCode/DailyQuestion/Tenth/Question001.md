# 1266. 访问所有点的最小时间
**难度：简单**

## 题目描述
平面上有 `n` 个点，点的位置用整数坐标表示 `points[i] = [xi, yi]`。请你计算访问所有这些点需要的 **最小时间**（以秒为单位）。

你需要按照下面的规则在平面上移动：

- 每一秒内，你可以：
    - 沿水平方向移动一个单位长度，或者
    - 沿竖直方向移动一个单位长度，或者
    - 跨过对角线移动 `sqrt(2)` 个单位长度（可以看作在一秒钟内水平和竖直方向各移动一个单位长度）。
- 必须按照数组中出现的顺序来访问这些点。
- 在访问某个点时，可以经过该点后面出现的点，但经过的那些点不算作有效访问。

## 示例与说明

> 本题考查的是在给定移动规则下，计算从一个点到下一个点所需的最短时间。由于每次移动可以是横向、纵向或对角线方向，因此两点之间的最短时间等于它们在 x 和 y 方向上的最大差值（即切比雪夫距离）。

## 解题思路

对于任意两个相邻点 `(x1, y1)` 和 `(x2, y2)`，从第一个点移动到第二个点所需的时间为：

$$
\text{time} = \max(|x2 - x1|, |y2 - y1|)
$$

因为：
- 如果 `|dx| == |dy|`，可以走对角线直接到达，耗时 `|dx|`；
- 如果 `|dx| > |dy|`，则先走对角线 `|dy|` 步，再走水平方向剩余 `|dx| - |dy|` 步，总时间仍为 `|dx|`；
- 同理，若 `|dy| > |dx|`，总时间也为 `|dy|`。

所以每一步的时间就是 `max(|dx|, |dy|)`。

## 算法步骤

1. 初始化总时间为 0。
2. 遍历相邻点对，计算每段移动所需时间。
3. 将每段时间累加到总时间中。
4. 返回总时间。

## 复杂度分析

- **时间复杂度**：O(n)，其中 n 是点的数量，只需遍历一次数组。
- **空间复杂度**：O(1)，只使用常量额外空间。

## 参考代码（Python）

```python
def minTimeToVisitAllPoints(points):
    total_time = 0
    for i in range(1, len(points)):
        dx = abs(points[i][0] - points[i-1][0])
        dy = abs(points[i][1] - points[i-1][1])
        total_time += max(dx, dy)
    return total_time
