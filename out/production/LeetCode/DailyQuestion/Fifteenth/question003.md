# 1009. 十进制整数的反码

**难度: 简单**

## 题目描述
每个非负整数 `N` 都有其二进制表示。例如，5 可以被表示为二进制 "101"，11 可以用二进制 "1011" 表示，依此类推。注意，除 `N = 0` 外，任何二进制表示中都不含前导零。

二进制的反码表示是将每个 1 改为 0 且每个 0 变为 1。例如，二进制数 "101" 的二进制反码为 "010"。

给你一个十进制数 `N`，请你返回其二进制表示的反码所对应的十进制整数。

---

## 示例说明
### 示例 1：
输入：5  
输出：2  
解释：5 的二进制表示为 "101"，其二进制反码为 "010"，也就是十进制中的 2。

### 示例 2：
输入：7  
输出：0  
解释：7 的二进制表示为 "111"，其二进制反码为 "000"，也就是十进制中的 0。

### 示例 3：
输入：10  
输出：5  
解释：10 的二进制表示为 "1010"，其二进制反码为 "0101"，也就是十进制中的 5。

---

## 提示：
- 0 ≤ N < 10^9

---

## 解题思路

### 核心思想
求一个数的二进制反码，可以通过位运算高效实现。对于一个正数 N，我们需要构造一个与 N 的二进制位数相同、且所有位都为 1 的掩码，然后用这个掩码与 N 进行异或运算。

### 关键观察
- 反码就是按位取反，即 `~N`
- 但 `~N` 会将 N 的二进制表示前面的 0 也取反，导致结果不正确
- 我们需要只对 N 的有效二进制位取反，即只对 N 的二进制表示长度内的位取反
- 因此需要构造一个与 N 的二进制位数相同、且所有位为 1 的掩码

### 算法步骤
1. 如果 N == 0，直接返回 1（0 的二进制反码是 1）
2. 计算与 N 的二进制位数相同的全 1 掩码：
   - 方法一：找到最高位的 1，然后构造掩码 = (1 << (二进制位数)) - 1
   - 方法二：通过循环构造掩码
3. 返回 N ^ 掩码

## 代码参考(python, java, c)

### Python 代码实现
```python
class Solution:
    def bitwiseComplement(self, N: int) -> int:
        if N == 0:
            return 1
        
        # 计算与 N 相同位数的全1掩码
        # 方法一：找到二进制位数
        bit_length = N.bit_length()
        mask = (1 << bit_length) - 1
        
        # 方法二：循环构造掩码
        # mask = 1
        # while mask < N:
        #     mask = (mask << 1) | 1
        
        return N ^ mask
```

### Java 代码实现
```java
class Solution {
    public int bitwiseComplement(int N) {
        if (N == 0) {
            return 1;
        }
        
        // 计算与 N 相同位数的全1掩码
        int mask = 0;
        int temp = N;
        while (temp > 0) {
            mask = (mask << 1) | 1;
            temp >>= 1;
        }
        
        return N ^ mask;
    }
}
```
