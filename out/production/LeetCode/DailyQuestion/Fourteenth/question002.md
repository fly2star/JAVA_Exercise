# 693. 交替位二进制数

**难度: 简单**

## 题目描述
给定一个正整数，检查它的二进制表示是否总是 0、1 交替出现：换句话说，就是二进制表示中相邻两位的数字不相同。

---

## 示例说明
### 示例 1：
输入：n = 5  
输出：true  
解释：5 的二进制表示是：101

### 示例 2：
输入：n = 7  
输出：false  
解释：7 的二进制表示是：111

### 示例 3：
输入：n = 11  
输出：false  
解释：11 的二进制表示是：1011

---

## 提示：
- n = 2^31 - 1（题目中提示可能不完整，实际应为 1 <= n <= 2^31 - 1）

---

## 解题思路

### 核心思想
检查二进制表示中相邻位是否相同。可以通过位运算高效实现，避免转换为字符串。

### 关键观察
- 交替位二进制数的特点是相邻位不同。
- 可以通过将原数右移一位后与原数进行异或操作：如果原数是交替位二进制数，那么异或结果的所有位应该都是 1（即形如 111...111）。
- 然后检查异或结果加 1 后与原结果进行与运算是否为零：`(n ^ (n >> 1)) & ((n ^ (n >> 1)) + 1) == 0`。

### 算法步骤
1. 计算 `n ^ (n >> 1)`，得到一个新数，如果 n 是交替位二进制数，那么这个新数的二进制表示应该全是 1。
2. 检查这个新数加 1 后与自身的与运算是否为 0：`(temp & (temp + 1)) == 0`。
3. 返回检查结果。

---

## 代码参考(python, java, c)

### Python 代码实现
```python
class Solution:
    def hasAlternatingBits(self, n: int) -> bool:
        temp = n ^ (n >> 1)
        return (temp & (temp + 1)) == 0
```

### Java 代码实现
```java
class Solution {
    public boolean hasAlternatingBits(int n) {
        int temp = n ^ (n >> 1);
        return (temp & (temp + 1)) == 0;
    }
}
```

### C 代码实现
```c
#include <stdbool.h>

bool hasAlternatingBits(int n) {
    long temp = n ^ (n >> 1);  // 使用 long 防止溢出
    return (temp & (temp + 1)) == 0;
}
```
