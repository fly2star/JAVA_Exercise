# 3453. 分割正方形 I

**难度：中等**

## 题目描述

给你一个二维整数数组 `squares`，其中 `squares[i] = [x_i, y_i, l_i]` 表示一个与 x 轴平行的正方形的左下角坐标 `(x_i, y_i)` 和正方形的边长 `l_i`。

找到一个最小的 `y` 坐标，它对应一条水平线，该线需要满足：**它以上正方形的总面积等于它以下正方形的总面积**。

> 答案如果与实际答案的误差在 $10^{-5}$ 以内，将视为正确答案。

### 注意：
- 正方形可能会重叠。
- 重叠区域应该被**多次计数**（即面积可以叠加）。

---

## 示例说明

例如，给定若干正方形，我们需要找到一条水平线，使得线上方所有正方形的总面积之和等于线下方所有正方形的总面积之和。由于正方形可能重叠，因此面积是累加计算的。

目标是求出满足条件的最小 `y` 值。

---

## 解题思路

### 核心思想：
- 所有正方形的总高度范围是从最低的 `y` 到最高的 `y + l`。
- 我们的目标是找到一个 `y`，使得：
  $$
  \text{上方面积} = \text{下方面积} = \frac{\text{总面积}}{2}
  $$

### 关键步骤：
1. **预处理每个正方形的上下边界**：
    - 每个正方形的上边界为 `y_i + l_i`。
    - 所有正方形的 `y` 值（包括 `y_i` 和 `y_i + l_i`）作为候选分割点。

2. **按 `y` 坐标排序**：
    - 收集所有 `y` 值（包括正方形的底边和顶边），并去重排序。

3. **扫描每个候选 `y`**：
    - 对于每个 `y`，计算其上方和下方的面积总和。
    - 使用“事件驱动”方法（类似扫描线）来高效计算面积。

4. **二分查找或线性扫描**：
    - 因为面积函数是单调递增的，可以在所有候选 `y` 中寻找第一个满足“上方面积 == 下方面积”的位置。

5. **精度要求**：
    - 由于允许误差在 $10^{-5}$ 内，可使用浮点比较或精确到小数点后6位。

---

## 算法步骤

1. 提取所有正方形的底边 `y` 和顶边 `y + l`，形成候选 `y` 值集合。
2. 排序这些 `y` 值。
3. 对每个候选 `y`，计算其上方和下方的总面积：
    - 上方面积：所有 `y_i < y` 的正方形中，位于 `y` 上方的部分面积。
    - 下方面积：所有 `y_i > y` 的正方形中，位于 `y` 下方的部分面积。
    - 注意：对于跨越 `y` 的正方形，需分段计算。
4. 寻找使上方面积 ≈ 下方面积的最小 `y`。

---

## 复杂度分析

- **时间复杂度**：O(n²)，其中 n 是正方形数量。对每个候选 `y`，遍历所有正方形计算面积。
- **空间复杂度**：O(n)，用于存储候选 `y` 值。

> 可优化为 O(n log n) 使用扫描线算法。

---

## 参考代码（Python）

```python
def splitSquares(squares):
    # 提取所有 y 值（底边和顶边）
    y_coords = set()
    for x, y, l in squares:
        y_coords.add(y)
        y_coords.add(y + l)
    
    y_coords = sorted(y_coords)
    
    total_area = sum(l * l for _, _, l in squares)
    target = total_area / 2.0
    
    # 枚举每个候选 y，计算上方面积
    for y in y_coords:
        above_area = 0.0
        below_area = 0.0
        
        for x, y_i, l in squares:
            top = y_i + l
            if y_i >= y:  # 完全在上方
                above_area += l * l
            elif top <= y:  # 完全在下方
                below_area += l * l
            else:  # 跨越 y
                above_area += (top - y) * l
                below_area += (y - y_i) * l
        
        if abs(above_area - below_area) < 1e-5:
            return y
    
    return y_coords[-1]  # 默认返回最大 y
