# 字符串构造问题

米小游定义一个字符串的**权值**为该字符串的**字母种类数量**。  
例如：
- `"hmh"` 的权值为 2（含 `'h'`, `'m'`），
- `"yyy"` 的权值为 1（仅 `'y'`）。

现在米小游给了你三个非负整数 $x, y, z$，她希望你构造一个长度为 $x + y + z + 2$ 的字符串，该字符串**仅由字符 `'m'`、`'h'`、`'y'` 组成**，并满足：

> 在该字符串包含的所有长度为 3 的子串中：
> - 恰好有 $x$ 个子串的权值为 1，
> - 恰好有 $y$ 个子串的权值为 2，
> - 恰好有 $z$ 个子串的权值为 3。

你能帮帮她吗？

---

## 输入描述

- 第一行输入一个正整数 $t$，代表询问的次数。
- 接下来的 $t$ 行，每行输入三个非负整数 $x, y, z$，用空格隔开。

**约束条件：**
- $1 \le t \le 10^4$
- $x + y + z \le 10^5$
- 每组询问中，$x, y, z$ **至少有一个是正数**

---

## 输出描述

对每次询问，输出一行答案：
- 如果无解，输出 `-1`；
- 否则输出一个长度为 $x + y + z + 2$ 的字符串，且**仅由 `'m'`、`'h'`、`'y'` 三种字符组成**；
- 若有多解，输出任意一个即可。

---

## 示例 1

### 输入
5
1 1 1
1 0 1
2 0 0
0 2 0
0 0 5


### 输出
mhyyy
-1
YYYY
yyhh
mhymhym


### 说明（部分验证）

- **第一组 `x=1, y=1, z=1` → `"mhyyy"`（长度 = 1+1+1+2 = 5）**  
  所有长度为 3 的子串（共 3 个）：
  - `"mhy"` → 字母 {m,h,y} → 种类数 = 3 → 权值 3 （对应 z=1）
  - `"hyy"` → 字母 {h,y} → 种类数 = 2 → 权值 2 （对应 y=1）
  - `"yyy"` → 字母 {y} → 种类数 = 1 → 权值 1 （对应 x=1）

- **第二组 `x=1, y=0, z=1` → `-1`（无解）**  
  长度 = 1+0+1+2 = 4，共 2 个长度为 3 的子串。  
  但要求：1 个权值 1 + 0 个权值 2 + 1 个权值 3 = 2 个子串 → 数量匹配；  
  然而，若存在权值 3 的子串（如 `"mhy"`），则其相邻子串必然共享 2 个字符，很难同时出现权值 1 的子串而不产生权值 2 的子串——实际无合法构造，故输出 `-1`。

- **第三组 `x=2, y=0, z=0` → `"YYYY"`（长度 = 2+0+0+2 = 4）**  
  子串：`"YYY"`, `"YYY"` → 均权值 1 → 共 2 个 

- **第五组 `x=0, y=0, z=5` → `"mhymhym"`（长度 = 0+0+5+2 = 7）**  
  子串共 5 个，需全为权值 3（即每个子串含 m/h/y 三者）。  
  `"mhymhym"` 的子串：
  - `mhy` → {m,h,y} → 3 
  - `hym` → {h,y,m} → 3 
  - `ymh` → {y,m,h} → 3 
  - `mhy` → 3 
  - `hym` → 3 
  满足 z=5。

> 💡 注：输入输出示例仅用于调试，后台判题数据一般不包含示例。

---

本题核心在于理解：**长度为 $L = x+y+z+2$ 的字符串，恰好有 $L-2 = x+y+z$ 个长度为 3 的子串**，需精确分配权值 1/2/3 的数量。  
构造策略通常依赖周期性模式（如 `mhy` 循环）或分段拼接（如全相同字符造权值 1，交替造权值 2，三元循环造权值 3）。



我们需要根据米小游给定的三个数字 $x, y, z$，用字符 'm', 'h', 'y' 拼接出一个总长度为 $x+y+z+2$ 的字符串，满足：
    恰好 $x$ 个子串权值为 1（类似 "mmm"）
    恰好 $y$ 个子串权值为 2（类似 "mmh" 或 "mhm"）
    恰好 $z$ 个子串权值为 3（类似 "mhy"）
长度为 $L$ 的字符串恰好包含 $L - 2$ 个长度为 3 的子串，所以我们只需要保证每次往字符串末尾添加 1 个字符，都能精准产生一个目标权值的子串即可。



我们可以采用“分段构造法”，一步一步来追加字符。在真正写代码之前，我们需要弄明白几个关键点：

步骤与原理：
    1. 寻找无解的“死胡同” (-1 的情况)：
        如果你想从权值 1 ("aaa") 直接变成权值 3 ("abc")，中间是一定要经过权值 2 ("aab") 的。因此，如果题目要求 $x > 0$ 且 $z > 0$，但偏偏不给你过渡的机会 ($y = 0$)，这就构成了绝对无解，直接输出 -1。
    2. 先搞定 $x$ (权值 1)：
        权值 1 最简单。我们先以 "mm" 开头，然后每追加一个 'm'，就能产生一个权值 1 的子串。追加 $x$ 次即可。
    3. 再搞定 $y$ (权值 2)：
        如果我们刚放完一堆 'm'，此时追加一个 'h'，就会形成 "mmh"，产生 1 个权值 2 的子串。接下来只要交替添加 'm' 和 'h'（如 "hmh", "mhm"），每一个新字符都会稳定贡献 1 个权值 2 的子串，直到消耗完 $y$。
    4. 最后搞定 $z$ (权值 3)：
        权值 3 要求三个字符互不相同。我们只需要观察字符串最后的两个字符，然后追加第三个没用过的字符即可。这样一直追加 $z$ 次。
